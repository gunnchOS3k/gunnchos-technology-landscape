## Observable question

> When I move relative to a window, room, or phone orientation, what wireless *experience* changes can I observe—and what RF root causes must I refuse to invent without calibrated evidence?

## Safety / privacy (hard stops)

- Legal end-user device use only.
- No unauthorized transmission, jamming, amplifiers, or homemade transmitters.
- No spectrum sniffing / packet capture on networks you do not administer.
- No climbing, no opening sealed devices, no improvised external antennas.
- Scrub SSIDs, locations, and account tokens from portfolio artifacts.
- See fixtures for the offline route when live networks are unsafe or unavailable.

## Distinctions to practice

| Observe | Infer only with more evidence |

| Icon lit / experience stalled | Exact interferer identity |
| Better near window | Calibrated path loss in dB |
| Orientation changed feel | Antenna gain figure |
| Stall time-of-day correlation | Unauthorized spectral occupancy map |
