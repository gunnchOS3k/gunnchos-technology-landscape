# LAB-RADIO-OBS-001 fixture — radio condition card

**Truth class:** illustrative teaching aid (not measured RF; not Quartet EVT).

## Path to label

```
Human (seat / hand orientation)
  → device radios + antennas (sealed; patterns matter)
    → obstacles / body / room geometry
      → shared spectrum / channel (regulated; contested)
        → AP or cellular access node
          → beyond-the-air path (packets / service)
            → human experience (smooth / stalled / icon-only)
```

## What you may observe safely

- Whether a familiar action feels usable
- Whether connection icons stay lit during a stall
- Coarse change when moving once (window vs interior) or rotating the phone
- UI text: connected, waiting, failed, nothing

## What you must not claim from outside observation alone

- Antenna gain or receiver sensitivity numbers
- Calibrated path loss or interference power
- Unauthorized spectral occupancy maps
- Device Quartet RF results (**PHYSICAL_PENDING**)
