Concepts in one breath

  1. Data → model → inference: input text + stored parameters → output.
  2. Local vs remote: on-device / offline-capable vs network-dependent service.
  3. Authn vs authz: prove identity vs decide allowed actions.
  4. Lifecycle: collect → use → retain → share → delete/redact.
  5. Privacy boundary: what is claimed to leave the device.
  6. Design principle: least privilege + psychologically acceptable controls.
  7. Trust / uncertainty: felt safety vs technical evidence; fluency ≠ truth.
