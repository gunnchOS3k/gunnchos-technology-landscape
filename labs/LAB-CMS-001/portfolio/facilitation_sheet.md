# Facilitation sheet — LAB-CMS-001 (Educator)

## Misconception probes

1. More cores always make every local action faster — **true or false?**  
2. RAM and storage are basically the same — **true or false?**  
3. The OS runs my app’s logic for me — **true or false?**  
4. If Wi-Fi is connected, lag must be the network — **true or false?**  
5. High CPU % always means CPU root cause — **true or false?**

*(Expected: all false or “not necessarily”; use fixtures to discuss.)*

## Fixture path

- Hand out `fixtures/FIG-CE3-009-monitor-transcript.md` and/or `sample_top_transcript.txt`.  
- Ask learners to mark each row observation vs inference.  
- Collect verbal/dictated tables if typing is a barrier.

## Equity

- Do not shame low-RAM devices.  
- Fixture route fully satisfies Explorer/Operator teaching goals.  
- No admin install required for baseline.

## Safety script

“Mild load only. If the device warns about heat or feels too hot, stop and close extra windows.”

## Privacy script

“No personal document text in screenshots. Redact names before anything leaves the device.”
