# Teach-back — LAB-CMS-001

Explain to a nontechnical person (2–4 short paragraphs):

1. **RAM vs storage** — working space for what is in use now versus files that stay after quit/reopen.  
2. **OS schedules / apps still compute** — the operating system decides *when* work gets processor time; the app still does its own calculating and drawing.

## Learner response

(Write here. Avoid claiming root cause without evidence.)

## Fixture practice answer (illustrative — not learner evidence)

RAM is the desk where papers you are reading sit; storage is the filing cabinet. When scrolling stuttered in the fixture, the notes app used more processor time for a moment and disk flickered briefly. The OS lined up that work with other programs; it did not “think the notes” for the app. Feeling warmer is a clue to check later with real sensors—not proof of a temperature number.
