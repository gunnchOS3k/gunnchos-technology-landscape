# Labs

Labs in this publication generate evidence artifacts.

Completion means: a claim is supported by an artifact—not merely that a command ran.

Learning-lab `status` values describe packaging readiness
(`IMPLEMENTED_DIGITAL`, `FIXTURE_VALIDATED`, `PHYSICAL_PENDING`, `EXTERNAL_DEPENDENCY`).
They never mean a learner "passed."

Shared CE lab contract: `labs/contracts/ce_lab_contract.schema.yaml`.
