# Scenario card — LAB-SYS-001 (fixture / illustrative)

**Label:** fixture / illustrative — not measured device evidence.  
**Audience:** Explorer / Educator fallback when a personal app cannot be used safely.

## Scenario

A learner opens a familiar “Notes” web app on a library laptop.

1. At wall-clock **0 s**, the title bar and navigation (**chrome**) appear.
2. The main area shows the text label **busy / loading**.
3. At about **1 s** online, a list of sample notes becomes **usable**.
4. In a second trial with Wi-Fi off, chrome still appears at ~0 s, but content stays on **failed to load** while chrome remains visible.

## Explorer task

Fill the observation table from this card only:

- chrome visible time (use the times above),
- content usable / failed,
- ≥3 visible cues,
- ≥3 guessed hidden parts (mark as inference).

## Educator note

Use this card to probe the misconception “if the screen shows an app frame, the whole system is ready.”
