# LAB-PKT-001 — Accessibility

- Keyboard-only path: browser demo controls are native buttons/selects; CLI is fully keyboard.
- Screen-reader: live status uses `aria-live="polite"`; tables have header cells; do not rely on color alone for Wi-Fi vs cellular vs error.
- Text equivalents: path diagrams must include a text description in `portfolio/diagram.md`.
- Fixture Route B required when learners lack personal hotspots, stable broadband, or admin rights for network tools.
- Captive portals often break assistive tech—document the exclusion and switch to fixtures rather than forcing login flows.
- Voice notes may substitute for written reflection where writing is a barrier (educator adaptation).
- Timebox: target ≤45–60 minutes baseline.
