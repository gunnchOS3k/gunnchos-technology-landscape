# Chapter 2 Career Map

Learner portfolio artifacts resemble professional artifacts; they do not guarantee employment.

| Layer | Example role | Professional artifact | Learner analogue |
|---|---|---|---|
| Interaction | UX / HCI | interaction specification | teach-back + notes |
| Input hardware | Embedded engineer | hardware/firmware interface | digitizer component card |
| Driver | Device-driver engineer | driver validation | failure-symptom writeup |
| Kernel/OS | OS engineer | scheduler/input notes | load vs latency notes |
| Application | App/frontend developer | event-handling implementation | Route A/B instrumentation |
| Performance | Performance engineer | trace/profile | latency budget |
| Network | Network engineer | packet/latency analysis | network timing table |
| Wireless | Wireless engineer | radio analysis | weak-signal equity discussion |
| Service | Backend/cloud/SRE | API/service evidence | remote failure domain notes |
| Security | Security engineer | threat model | permissions discussion |
| Accessibility | Accessibility engineer | conformance review | keyboard/switch/voice path |
