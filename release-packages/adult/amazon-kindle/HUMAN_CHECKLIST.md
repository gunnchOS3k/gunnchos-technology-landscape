# Human-only checklist — `amazon-kindle`

Do **not** store passwords, API keys, tax IDs, or bank details in this repo.

- [ ] Retailer/distributor account exists (owner-created; not by agents)
- [ ] Tax/banking complete in retailer console (off-repo)
- [ ] ISBN slots filled or free-ID choice accepted intentionally
- [ ] Metadata matches `publication/metadata/adult-book.yaml`
- [ ] Rights wording matches ARR / free-access policy
- [ ] KDP Select remains **unenrolled** if this is Kindle and wide-access is active
- [ ] EPUBCheck / Kindle Previewer / platform previewer run on final files
- [ ] Cover meets platform geometry
- [ ] Print-only: live cost + cover calculator completed
- [ ] No fabricated reviews, awards, or Gate 3 PASS claims on detail page
- [ ] Owner approval recorded before clicking Publish
