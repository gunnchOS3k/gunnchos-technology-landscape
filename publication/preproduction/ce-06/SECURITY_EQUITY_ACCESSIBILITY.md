## Security boundaries

- Capstone forbids unauthorized access, scanning, exploitation, or password capture.  
- Diagnosis uses **owned devices**, benign demos, or fixtures.  
- Telemetry helpers must default to **least data** and local storage.  
- Teach that “more logs” can expand attack/privacy surface (tradeoff).  
- Identity/session expiry is a first-class contract condition, not an afterthought.

## Privacy concerns

- Portfolio scrub: secrets, tokens, private messages, precise location, classmate PII.  
- Screenshots cropped; sample tables preferred.  
- Distinguish observability for learning from surveillance.  
- Cloud AI / analytics features in chosen experiences: discuss data leaving the device (CE-5 synthesis) without fear-mongering.

## Accessibility concerns

- SC-10: equivalent feedback on keyboard / switch / screen-reader paths.  
- Timing activities allow extended time; avoid seizure-risk flicker demos.  
- Figures in later drafting need alt text + text equivalents (publication requirement).  
- Explorer path must work **without** DevTools (status UI + notes).  
- WCAG 2.2 informs intent; labs do not certify conformance.

## Digital-equity implications

- Strong-device / strong-link authors can falsely conclude the contract is “fine.”  
- Metered data, shared devices, older hardware, and intermittent connectivity change acceptable bounds.  
- Offline/fixture fallback is an **equity feature**, not a lesser path.  
- Improve plans should ask: *who benefits / who is left out?*  
- WAIKE phone-first / low-cost principles are adjacent intent evidence—not proof of completed inclusion.

## Safety boundaries

- No device modification that voids safety or legality.  
- No social-engineering classmates for “tests.”  
- Stop if reproduction risks account lockout; switch to fixtures.  
- Mental-safety: failure demos framed as learning, not humiliation.

## Ethical framing

- Evidence honesty over performative PASS.  
- Do not blame individuals for systemic contract failures.  
- Improvements that boost metrics while excluding people fail the rubric’s Improve dimension.  
- Educators adapt labs without requiring paid cloud accounts.
