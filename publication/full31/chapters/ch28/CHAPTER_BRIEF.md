## Reader promise

Use models, simulations, and twins as bounded stand-ins for reality—and make research steps reproducible at a declared SHA/fixture.

## Anchor human moment

A simulation says a design is fine, but the real device/network path fails; or a peer cannot reproduce a result because the environment was not pinned.

## Teaching model

`moment → notice → ecosystem → signal → components → Stability Contract → Try/Build → secure/include → career → check → glossary`

Central chain: **Human experience → system → component → code → network → society**

## Measurable outcomes (Explorer → Researcher)

| Pathway | Outcome |
|---|---|
| Explorer | Explain model/simulation vs measured world in ordinary language. |
| Operator | Run a fixture simulation and label outputs illustrative vs measured. |
| Builder | Pin environment (SHA, seeds, fixture IDs) for a small experiment. |
| Engineer | State twin/simulation validity bounds and failure modes. |
| Researcher | Write a reproducibility card: inputs, code SHA, fixture, limitations. |

## Stability Contract (chapter conditions)

- Model validity bounds explicit
- Seeds/fixtures/SHAs pinned for claimed reproduction
- Observation/inference labels on simulated outputs
- No silent promotion of simulation to physical proof

## Security / equity / accessibility (integrated)
