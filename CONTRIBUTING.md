# Contributing

Thank you for helping build *The Technology Landscape*.

## Rules

1. Never invent device capabilities, benchmarks, deployments, awards, partnerships, or learner outcomes.
2. Repository-derived facts require accepted-`main` evidence, commit SHA, and claim registration.
3. Do not implement Wave work directly on `main`; use a feature branch.
4. Prefer original diagrams; record third-party materials in the rights register before inclusion.
5. Keep Explorer-readable explanations even when adding Engineer/Researcher depth.
6. Separate observation, interpretation, and causal claims in labs.

## Local workflow

```bash
make setup
make validate
make test
make preview
```
