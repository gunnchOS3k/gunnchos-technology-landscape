# Kids Accessibility Requirements

**Status:** `DRAFT_INTERNAL`  
**Extends:** adult `publication/ACCESSIBILITY_REQUIREMENTS.md` and `STYLE_BIBLE.md`  
**Non-claim:** Requirements checklist — automated checks do not certify WCAG/EPUB accessibility.

## Principle

Disability does **not** lower intellectual expectations. Provide alternate interaction routes; never ship a single gated path to a concept.

## Considerations (all bands)

| Area | Requirements |
| --- | --- |
| Low vision | High contrast options; large type targets by band; scalable digital text where reflowable |
| Color vision | Color never sole encoding; patterns/labels |
| Hearing | Captions + transcript for audio/video; print stands alone |
| Dyslexia / readability | Clear fonts (avoid decorative body); adequate spacing; short lines for young bands |
| Motor | Large tap targets if digital; no precision-only gestures; print activities work without fine motor perfection |
| Neurodiversity | Predictable cadence; reduce clutter; avoid surprise loud SFX; allow skip/ pause |
| AAC / communication differences | Visual supports; accept multimodal responses (point, gesture, device, speech) |
| Sensory sensitivities | Soft audio ceilings; no seizure-risk flash; optional reduce-motion |
| Multilingual families | Home-language caregiver prompts; do not fake validated translations |
| Cognitive differences | Chunking; repetition with variation; concrete examples first |

## Figure / print a11y

Every figure: ID, caption, alt text, text equivalent, reading order when complex, source/status. Same honesty vocabulary as adult book.

## Caregiver prompts

Prompts must be adaptable (“point, tap AAC, or say”) and must **not** become developmental screening.

## Digital

- Keyboard / switch-friendly where interactive.
- Easy exit.
- No information only in hover or color.
- Privacy: no unnecessary biometric or always-on mic requirements for core learning.
