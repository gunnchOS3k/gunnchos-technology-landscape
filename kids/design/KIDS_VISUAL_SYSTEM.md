# Kids Visual System (by age band)

**Status:** `DRAFT_INTERNAL`  
**Evidence:** CME-001–007, CME-016, CME-022–024; adult `STYLE_BIBLE.md` color-never-sole rule applies.  
**Non-claim:** Spec targets for illustrators/layout — not final art direction lock.

Global rules:

- Color never sole encoding (pair with label, shape, or pattern).
- Avoid sensory overload; whitespace is a feature.
- Distinct character silhouettes; max concurrent named characters rises slowly with age.
- Motion (digital): purposeful, short, never seizure-risk flash patterns.

## Illustration tone

Warm, concrete, technology-as-things-people-use — not neon cyber overload, not horror glitch aesthetics. Prefer real-world anchors (buttons, lights, wires-as-paths metaphors labeled as metaphors).

## Digital layout

Fixed-layout EPUB only when illustration–text spatial relationship is pedagogically required (younger picture books). Prefer reflowable for ELEM text-heavy titles. See `kids/publication/KIDS_FORMAT_MATRIX.yaml`.
