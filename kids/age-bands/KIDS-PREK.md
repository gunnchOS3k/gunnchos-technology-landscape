# KIDS-PREK Age-Band Architecture

**Band ID:** `KIDS-PREK`  
**Guide ages:** 4–6 years (guide, not deadline)  
**Status:** `DRAFT_INTERNAL`

## Learner profile

Ready for rule talk, paths, and simple fairness/privacy ideas. Emerging letter/word awareness varies widely — design must not assume fluent reading.

## Caregiver role

Caregiver + optional educator guide. Co-use still valuable.

## Language complexity

25–60 words/spread; introduce 1–2 precise terms with gloss.

## Page / spread density

2–4 focals; activity pages allowed.

## Visual complexity

Scenes + simple path diagrams; legends if color-coded.

## Interaction type

NOTICE→PREDICT→TRY→EXPLAIN→SAFE+FAIR→TEACH.

## Concept depth

Messages follow paths/rules; instructions can be wrong and fixed; private vs shared.

## Safety constraints

Password/privacy metaphors without fearmongering; no data harvest.

## Digital / media constraints

Picture/activity + caregiver/educator PDF; wait prompts.

## Assessment philosophy

Show-what-you-made; rubrics only for educators if external — not child shame.

## Portfolio / artifact expectations

Simple artifact: labeled drawing, cardboard path, role-play photo (offline).
