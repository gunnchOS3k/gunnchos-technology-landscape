# KIDS-BABY Age-Band Architecture

**Band ID:** `KIDS-BABY`  
**Guide ages:** 0–18 months (guide, not deadline)  
**Status:** `DRAFT_INTERNAL`

## Learner profile

Sensory-motor explorers. Attend to faces, high-contrast objects, contingent cause→effect. Video/print 'learning' without a caregiver is weak; social routines dominate.

## Caregiver role

Primary learner partner. Follow gaze, name, wait, respond, repeat. Read-aloud is for the dyad, not performance.

## Language complexity

Caregiver-facing micro-text (0–8 words/spread). Child may hear labels; no child reading expectation.

## Page / spread density

1 focal object; lots of board real-estate empty.

## Visual complexity

Ultra-high contrast; near-empty backgrounds; 0–1 character silhouette.

## Interaction type

LOOK → POINT → NAME → WAIT → RESPOND → REPEAT. Physical cause/effect with household objects.

## Concept depth

Precursors only: action→response, here→there, light on/off as 'signal.' No abstract networks/AI.

## Safety constraints

Choke-safe board book production (vendor). No screens as default. No data collection.

## Digital / media constraints

Print-first. Optional caregiver audio. No solo interactive app.

## Assessment philosophy

No testing. Informal delight/attention only — never screening.

## Portfolio / artifact expectations

None for child. Caregiver may note favorite pages (optional, private, offline).
