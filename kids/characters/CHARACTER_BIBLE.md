# Character Bible — Cast Options (No IP Lock)

**Status:** `DRAFT_INTERNAL` — **no final name/visual IP lock without owner decision**  
**Evidence:** CME-016–018 (stable cast, parasocial learning, participatory prompts)  
**Ethics:** Original IP only. Study methodology of successful kids media; do **not** imitate living shows’ characters, visual identity, dialogue, songs, or plots.

## Design requirements (all options)

- Distinct silhouettes; emotionally legible faces/poses  
- Culturally inclusive; non-stereotyped  
- Disability / accessibility-inclusive design opportunities (e.g., AAC user, limb difference, sensory aids — presented as ordinary belonging)  
- Recurring relationship dynamics + humor + teach-back  
- Characters embody **perspectives**, not literal misrepresentation of system components  
- **No “AI knows everything” trope**  
- Roles covered: curious explorer; builder/hardware; instructions/software; signals/network; safety/privacy/fairness

## Shared relationship dynamics

1. Explorer notices → Builder shows the part → Instructions proposes steps → Signals tests the path → Safety asks who can see / who is left out.  
2. Mistakes are normal; repair is celebrated.  
3. Teach-back: characters ask the child/caregiver to explain.  
4. Humor without humiliation.
