# Caregiver Guide System

**Hard rules:** Do **not** turn prompts into developmental screening. No child data collection. Home language welcome.

## Purpose

For ages ~0–5 especially, the caregiver *is* the learning interface. Guides teach responsive interaction — not performance pressure.

## Core moves (0–5)

1. **Follow** the child’s attention (eyes, pointing, body).
2. **Name** what they notice (in the family’s home language) — e.g. “You touched. It changed.”
3. **Wait** for a response (gesture, sound, AAC, word, or pause).
4. **Point / gesture** together.
5. **Repeat** with small variation across the day.
6. **Connect** to household objects (safe, supervised: lamp switch, remote, toy button).
7. **Avoid forcing** performance or “correct” answers.
8. **Adapt** for disability / sensory needs (volume, seating, alternate responses, shorter sessions).
9. **Stop early** if the child disengages — stop is success.

Baby/toddler cadence: `LOOK → POINT → NAME → WAIT → RESPOND → REPEAT`.

## For elementary (K–5/6)

Caregiver/educator role shifts toward:

- co-observing local vs networked actions
- helping separate “I saw” from “I guess”
- protecting privacy/safety choices
- celebrating process evidence in a portfolio (no ranking)

## Prompt safety checklist

- Multimodal acceptance (say / point / AAC / draw)
- No age-norm scare language (“by 2 your child must…”)
- No upload of child photos required
- Offline activities preferred
- Stop anytime — celebrated
- Autoplay off; no infinite scroll; easy exit visible in digital previews

## What guides must not do

- Diagnose, score development, or compare children
- Shame screen-time guilt spirals
- Demand English-only
- Replace pediatric advice
- Collect child personal data via prototype tools
