# Accessibility Notes — KIDS-PREK

**Status:** working-draft guidance · NOT CHILD-VALIDATED · NOT PUBLICATION-READY

Do not lower conceptual expectations automatically because of disability. Offer routes; keep the ideas.

## Routes by need

| Need | Route in this manuscript |
| --- | --- |
| Low vision | High-contrast diagrams; large labels; describe figures aloud; tactile card stacks |
| Color vision | Shape + text redundancy; color never sole encoding |
| Hearing | Visual sequence cards; written try-it prompts for caregivers; no mandatory audio |
| Dyslexia / readability | Short lines; caregiver read-aloud; word cards with icons |
| Motor differences | Pointing, partner builds, large cards, no fine-motor-only success criteria |
| Neurodiversity | Predictable cadence; easy stop; low clutter; one focal action |
| AAC / communication differences | Symbol cards for input/output/part/system/safe/private; accept multimodal responses |
| Sensory sensitivity | Paper-first options; short sessions; no autoplay |
| Multilingual families | Caregiver may translate glosses; keep core terms stable across languages |

## Inclusive fairness

Unit SAFE and BUILD treat accessibility tools as ordinary belonging, not optional extras.

## Non-claims

These notes are design routes, not clinical assessments.
