Do not lower conceptual expectations automatically because of disability. Provide routes.

## Routes

| Need | Route in this draft |
| --- | --- |
| Low vision | High-contrast SVGs; large print paper copies; read-aloud OK |
| Color vision | Shape + label encoding; legends; never color-alone |
| Hearing | Visual turn timers (clap + raised hand); written algorithm cards |
| Dyslexia / readability | Short chunks; glossary sidebars; partner scribe |
| Motor differences | Partner placement for cards; oral teach-back; large tap targets if digital later |
| Neurodiversity | Predictable cadence; easy stop; low sensory clutter backgrounds |
| AAC / communication | Symbol-supported teach-back; choice boards for local/network |
| Sensory sensitivity | No seizure-risk flash; moderate pacing; quiet corner OK |
| Multilingual families | Caregiver may translate try-its; keep concept words stable when possible |

## Figure a11y

All shipped SVGs include `<title>` and `<desc>`, labeled reading order, and color-not-sole-encoding notes in meta.
