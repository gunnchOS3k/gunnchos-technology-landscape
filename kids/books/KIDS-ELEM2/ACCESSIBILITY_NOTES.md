## Reading order

Figures encode reading order: title → focal diagram → body excerpt. Color is never the sole encoding; labels and patterns accompany shapes.

## Alternate participation routes

- Partner scribe for written labs
- Verbal teach-back instead of long writing
- Large-print SVG printouts (800×500 source)
- AAC-friendly short EMIT scripts (Explain / Measure / Improve / Teach as four cards)
- Extended time; easy stop without penalty

## Sensory / pacing

Moderate diagram density for junior reference. No seizure-risk flash patterns. User-paced digital transitions only if later packaged.

## Inclusive representation

Provisional Signal Crew should be illustrated with inclusive, non-stereotyped design opportunities per Character Bible (AAC, limb difference, sensory aids as ordinary belonging). Final character art not locked.

## Non-claims

These notes are design targets, not validation evidence that materials “work for all learners.”

## Route checklist (integrator completeness)

- Low vision routes: large print, high contrast, described figures
- Color vision: redundant non-color cues
- Hearing: visual alternatives; no audio-only requirements
- Dyslexia / readability: short lines, clear spacing
- Motor differences: large targets, partner-assisted options
- Neurodiversity: predictable cadence, easy stop, low clutter
- AAC / communication differences: gesture/device/partner responses count
- Sensory sensitivity: quiet route available
- Multilingual families: caregiver translation welcome
